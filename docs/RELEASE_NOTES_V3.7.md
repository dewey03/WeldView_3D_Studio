# WeldView 3D Studio 升级与打包说明（单V坡口深度识别 · 一键生成焊缝 · 人工补选 · 焊接图纸辅助判定）

## 一、 本次四大核心功能升级概览

针对最新工程反馈的四项核心诉求，我们对 **WeldView 3D Studio** 桌面安装包（`WeldView_3D_Studio_Setup_V3.7.exe`）与独立交互式 3D 效果图（`21000顶梁一焊新_交互式3D焊缝效果图_V3.7.html`）进行了全面重构升级：

| 序号 | 用户核心需求 | 原有瓶颈与漏检根因 | 本次升级方案与实现效果 |
| :--- | :--- | :--- | :--- |
| **1** | **进一步提高坡口焊缝检测效果，解决大量单V坡口被误判为角焊缝的问题** | ① 旧版仅凭本零件单侧二面角 `e.theta < 58°` 判定坡口，而 **单V/单边V坡口（Single-V / HV）** 在尖根处与背壁夹角为 $\arccos(-0.707)=135^\circ$，在带钝边（Y型坡口）处根部边二面角为 $90^\circ$，导致单V坡口被大面积误判为角焊缝；<br>② 旧版 `groupWeldEdges` 将板厚一侧的单V坡口边与另一侧的背侧角焊缝边混并进同一条焊缝，导致单V坡口被角焊缝吞并 | ① **法平面正交截面坡口扫描算法（`detectCrossPartJoints` V3.8）**：沿交界切向 $\vec{T}$ 的法平面在 $15.5\text{ mm}$ 半径内同时扫描 `partA` 与 `partB` 的斜面（与母材主壁面夹角 $22^\circ\sim 68^\circ$ 且与配对壁面构成锐角槽口），精准识别尖根单V坡口与带钝边单V坡口，自动标注 `grooveSubType = "singleV"`（`单V 45°`）与 `V`（`对称V 60°`）；<br>② **坡口/角焊异侧分离聚类**：严禁将单V坡口边与背侧普通角焊缝边混并；在 `21000顶梁一焊新` 上精准识别出 **29 条单V坡口焊缝（18.38 m）**（较旧版新增检出 8 处此前被误判或吞并的重要单V坡口主焊缝） |
| **2** | **自动识别后增加“一键自动生成焊缝”功能，免去焊缝多时人工挨个选择** | 旧版导入模型后仅标识待焊边，或需进入拾取模式逐条点击边线创建；且旧版自动识别存在 220 条上限并跳过低置信度候选边 | 新增 **`⚡ 一键生成焊缝`（`autoGenerateAllWeldsV38`）**：<br>① 在主工具栏、下拉菜单、底部拾取条及交互式 3D HTML 顶栏新增醒目的 **`⚡ 一键生成焊缝`** 按钮（快捷键 `Shift+A`）；<br>② 支持 **「⚡ 一键生成全部焊缝（含低置信度全量生成）」** 与 **「仅生成单V/坡口焊缝」**，无需人工逐个点选边线即可瞬间完成整机上百条 3D 焊缝建模与定额核算 |
| **3** | **遇见自动识别未检测到的焊缝，增加人工选择补焊功能** | ① 旧版 `rebuildCandidateEdges` 与 `drawHud` 存在 `if (!e.weldable) continue;` 过滤，导致未检出的几何边在视口中完全不可见、悬停不亮；<br>② 无特征边部位无法直接手绘建缝；<br>③ 手动选坡口焊缝若无自动测量值会报错拦截 | 新增 **`✍️ 人工补选焊缝`（双模式全开放补选）**：<br>① **模式 A（🔗 任意特征边开放点选）**：彻底解除非可焊边屏蔽，全模型所有几何边均开放点选（紫=单V坡口候选、蓝=角焊候选、灰=未检出开放边），且手动选择单V坡口时自动填充默认 $45^\circ$ 参数，绝不报错拦截；<br>② **模式 B（📍 模型表面两点手绘焊缝）**：在桌面端与导出的 3D HTML 中，均支持直接在三维零件表面依次点击**起点**与**终点**，自动提取表面法向并实时生成贴合母材的三棱柱 3D 焊道，支持一键撤销 |
| **4** | **支持通过导入焊接图纸的形式辅助判定焊缝** | 缺乏二维焊接施工图/工艺表导入与三维零件自动关联判定机制 | 新增 **`📐 导入图纸判定`（焊接工程图纸导入与智能辅助判定工作台）**：<br>① 支持上传二维焊接施工图（`.png / .jpg / .webp / .pdf`）与焊缝工艺表（`.csv / .json / .txt`），提供左侧图纸预览区；<br>② 内置 **GB/T 324 / AWS 焊缝符号与件号对解析器**（识别 `TM220.010101 ↔ TM220.010106`、`单V45°`、`V60°`、`K值`、`人/机`），预置 `21000顶梁一焊新` 15 条核心施工图坡口规则，点击 **`⚡ 按图纸规则一键判定并修正三维焊缝`** 即可批量校准三维焊缝坡口型号与尺寸 |

## 三、 操作指南（桌面端软件 & 交互式 3D HTML 通用）

1. **⚡ 一键自动生成焊缝**：
   - 在桌面软件导入 STEP/STL 模型后，点击顶部工具栏蓝色高亮按钮 **`⚡ 一键生成焊缝`**（或在交互式 3D HTML 中点击 **`⚡ 一键生成焊缝`**），系统无需人工逐个选择，一步自动完成全模型单V坡口检测、角焊缝识别与 3D 焊道实体生成；也可切换 **`仅生成坡口焊缝`** 单独检视全部 29 条单V坡口焊缝。
2. **✍️ 人工补选未检测到的焊缝**：
   - 点击顶部工具栏橙色高亮按钮 **`✍️ 人工补选焊缝`**：
     - **选边补焊模式（桌面端）**：全模型所有几何特征边全部开放点选，点击任意边线并选择 `单V坡口 (45°)` / `对称V坡口 (60°)` / `角焊缝` 及 `K值` 即可创建；
     - **两点手绘焊缝模式（桌面端 & 3D HTML 通用）**：直接在 3D 模型表面漏检部位依次点击**起点**与**终点**，系统立即沿着两点间的母材表面生成带真实截面的 3D 焊道，并自动计入右侧焊缝清单与定额统计表（支持点击 `撤销补选` 回退）。
3. **📐 导入焊接图纸辅助判定焊缝**：
   - 点击顶部工具栏绿色高亮按钮 **`📐 导入图纸判定`**，弹出双栏工作台：
     - 左侧可点击 **`📂 选择图纸文件`** 导入 PNG/JPG 图纸图片、PDF 工艺卡或 CSV/JSON 焊缝明细表进行对照预览；
     - 右侧自动解析或编辑 `零件A件号, 零件B件号, 坡口型号(单V45°/V60°/角焊), 焊脚K, 人/机` 规则表，点击 **`⚡ 按图纸规则一键判定并刷新三维焊缝`**，即可根据图纸要求批量校准三维模型中的坡口型号与焊脚尺寸。
