关于 WeldView 3D Studio
WeldView 3D Studio V3.3 (Professional CAD Edition)
架构：C# 托盘常驻宿主 (动态端口) + Python SolidWorks COM 桥接 (:18766) + WebGL PBR
• 标准依据：GB/T 324-2008（焊缝符号）、GB/T 985.1（气焊/电弧焊坡口基本形式与尺寸）、ISO 2553
• 几何精度声明：曲线真实弧长积分误差 < 0.1%，坡口法向夹角测量精度 ±1°，尺寸误差 ≤ 0.5 mm
• 数据安全承诺：所有 CAD 图纸与工程文件 100% 本机离线解析，图纸不出本机
• 授权许可：企业工业版永久授权 (AppUserModelID: WeldView.3DStudio.2)
