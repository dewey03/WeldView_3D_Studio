# WeldView 3D Studio

> 焊接结构三维焊缝识别与焊材定额核算工作台 —— 单V坡口深度识别 · 一键生成焊缝 · 人工补选 · 焊接图纸辅助判定

WeldView 3D Studio 面向钢箱梁、顶梁等大型焊接结构件，从三维模型（STEP / STL）自动识别可焊边与坡口类型，生成带真实截面的 3D 焊道实体，并按坡口型号自动核算焊材消耗与标准定额工时。

当前版本：**V3.7**

---

## 1. 核心能力

| 能力 | 说明 |
| :--- | :--- |
| **单V坡口深度识别** | 基于**法平面正交截面坡口扫描算法**，沿交界切向的法平面在 15.5 mm 半径内同时扫描配对零件斜面，精准区分单V坡口（尖根 / 带钝边）与普通角焊缝，解决单V坡口被大面积误判为角焊缝的问题 |
| **坡口 / 角焊异侧分离聚类** | 禁止将单V坡口边与背侧角焊缝边混并为同一焊缝，保证焊缝条数与长度的真实性 |
| **⚡ 一键生成焊缝** | 快捷键 `Shift+A`，免逐条点选，一步完成全模型坡口检测、角焊识别与 3D 焊道建模；支持"仅生成坡口焊缝" |
| **✍️ 人工补选焊缝** | 双模式：模式 A 全模型几何边开放点选；模式 B 在三维表面两点手绘焊缝，自动提取表面法向生成贴合母材的焊道 |
| **📐 导入图纸判定** | 支持 PNG / JPG / WEBP / PDF 施工图与 CSV / JSON / TXT 工艺表导入，内置 GB/T 324 与 AWS 焊缝符号解析器，按图纸规则批量校准三维焊缝坡口型号与焊脚尺寸 |
| **定额核算** | 按焊缝类型、坡口型号、K 值、施焊方式（人 / 机）输出焊材消耗（kg）与标准工时（min） |

## 2. 快速开始

### 方式一：直接打开交互式 3D 效果图（免安装）

```bash
# 克隆仓库后，直接用浏览器打开
index.html
```

`index.html` 是**完全自包含**的单文件应用（无外部 CDN 依赖，可离线运行），双击即可在浏览器中查看交互式三维焊缝效果图，支持旋转、剖切、焊缝高亮、清单联动与统计筛选。

> 建议使用 Chrome / Edge 最新版本以获得完整 WebGL 性能。

### 方式二：安装桌面端

从 [Releases](../../releases) 页面下载 `WeldView_3D_Studio_Setup_V3.7.exe` 安装包运行。桌面端在 3D 效果图基础上增加 STEP / STL 模型导入与完整编辑能力。

## 3. 典型样件识别结果

以 `21000顶梁一焊新` 为基准样件（V3.7 实测）：

| 指标 | 数值 |
| :--- | :--- |
| 焊缝总数 | **162 条** |
| 总长 | **167.13 m** |
| 坡口焊缝（Groove） | **29 条 / 18.38 m**（全部识别为单V坡口 45°） |
| 角焊缝（Fillet） | **133 条 / 148.76 m** |
| 机器人焊（机） | 122 条 / 136.45 m |

## 5. 技术说明

- **渲染**：原生 WebGL，无第三方三维引擎依赖，单文件即可运行
- **几何处理**：法平面正交截面扫描（cross-part joint detection），二面角 + 配对壁面锐角槽口双重判据
- **坡口判定阈值**：斜面与母材主壁面夹角 `22° ~ 68°`，扫描半径 `15.5 mm`
- **焊缝建模**：按坡口类型（单V 45° / 对称V 60° / 角焊）与 K 值生成带真实截面的三棱柱焊道实体
- **数据标准**：GB/T 324 焊缝符号、AWS 焊缝符号
